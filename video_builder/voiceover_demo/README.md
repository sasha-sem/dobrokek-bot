# Пробная озвучка мемов

Проба использует до трёх мемов из текущего экспорта с готовыми репликами.
Если реплик ещё нет, запустите `make narrations`.

Синтез выполняет Microsoft Edge TTS через
[edge-tts](https://github.com/rany2/edge-tts). Нужен интернет; сервису отправляется
только текст реплик. API-ключ не требуется.

Из `video_builder/`:

```bash
poetry run python -m pip install -r voiceover_demo/requirements.txt
poetry run python voiceover_demo/build_preview.py
poetry run python voiceover_demo/build_preview.py --voice en-US-AndrewMultilingualNeural
poetry run python voiceover_demo/build_preview.py --voice ru-RU-SvetlanaNeural
```

Результаты:

- `output/random/preview.mp4` — случайный голос для каждого мема (по умолчанию);
- `output/en-US-AndrewMultilingualNeural/preview.mp4` — мужской голос Andrew;
- `output/ru-RU-SvetlanaNeural/preview.mp4` — женский голос;
- рядом с каждым превью — отдельные вставки, WAV с паузами и `timeline.json`.

В режиме `random` для каждого мема независимо выбирается Andrew или Svetlana
с равной вероятностью. Все реплики одного мема читает один выбранный голос.
При новой сборке выбор выполняется заново; последовательные мемы могут получить
один и тот же голос. Выбор сохраняется для каждого мема в `timeline.json`.
Чтобы воспроизвести последовательность голосов, можно указать `--seed 1`.

Для своей пробы можно указать `--manifest` со списком `samples` или создать
локальный `samples.json` для Edge TTS. Каждый образец задаёт `id`, `image`
и `segments`. Пути к изображениям считаются относительно `video_builder/`.
Перед чтением добавляется 0,45 с,
после — 1,2 с. Видео длится столько, сколько нужно записи с паузами,
с округлением вверх до кадра при 30 fps. Лишняя тишина в начале и конце
каждого ответа сервиса обрезается с небольшим запасом вокруг речи;
паузы внутри фраз сохраняются. Музыка не добавляется.

Озвучка кэшируется в общем `../narrations/audio/` по тексту, голосу и темпу. Повторная сборка
использует готовые записи; изменение реплики создаёт новую запись.
Старые записи из `cache/` также используются и переносятся в общий кэш.
Кэш и `output/` исключены из Git и находятся отдельно от `temp_clips/`.

Для мужского варианта выбран многоязычный Andrew, читающий русский текст.
При проверке `ru-RU-DmitryNeural` стабильно возвращал пустые ответы
на фразы из этой пробы. Временные сетевые ошибки и пустые ответы повторяются
до трёх раз, затем сборка завершается с сообщением об ошибке.

Для рендера нужен FFmpeg с `libx264`; скрипт также умеет использовать FFmpeg
из `imageio-ffmpeg`, уже входящего в окружение MoviePy. Основной конвейер
сборки для этой пробы запускать не нужно.
