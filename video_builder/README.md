# Сборка видео

Команда `make clips` подготавливает клипы выпуска и озвучивает фото-мемы
голосами отправителей из профилей VoiceStudio. Длительность картинки
рассчитывается по записи с паузами. Без озвучки мем показывается 5 секунд.

## Полный выпуск

Положите экспорт Telegram в `export/`, укажите номер выпуска и запустите сборку.

```bash
make all EP=12
```

Выпуск сохраняется в `result/output.mp4`. Отдельными шагами можно запустить
`make assets EP=12`, `make clips` и `make video`. `make clips` добавляет в середину
выпуска фото-мемы с паузами, интонацией и числительными, подготовленными LLM.
При повторном монтаже готовые мемы берутся из кэша. `make video` склеивает
подготовленные клипы, добавляя доступные заставки.

## Распознавание через LM Studio

1. Установите [LM Studio](https://lmstudio.ai/) и скачайте модель с **Vision Input**.
   Для текущей установки выбрана
   [Qwen3.5-9B](https://lmstudio.ai/models/qwen/qwen3.5-9b) в GGUF Q4_K_M.
2. Для начала используйте контекст 8192. Если модель ещё не загружена,
   сборщик загрузит её с этим контекстом. У моделей, поддерживающих отключение
   reasoning (в том числе выбранной Qwen3.5-9B), скрипт задаёт `reasoning=off`
   через нативный API. Переключатель Enable Thinking в интерфейсе искать не нужно.
3. В Developer запустите локальный сервер. По умолчанию используется
   `http://127.0.0.1:1234`. Если загружено несколько моделей с Vision Input,
   задайте точный идентификатор через `LM_STUDIO_MODEL`.
4. В `video_builder/` установите зависимости и подготовьте тексты:

```bash
make install
make narrations
```

На RTX 3070 Ti Laptop с 8 ГБ VRAM при нехватке видеопамяти уменьшите GPU Offload:
часть модели будет работать в оперативной памяти. Реальный расход памяти и скорость
проверяются после загрузки модели с изображением.

LM Studio получает изображения локально и возвращает текст с порядком реплик
и паузами. Сценарии сохраняются в `narrations/scripts.json`, отчёт с картинками —
в `narrations/scripts.md`. Повторная сборка использует сценарии, пока картинка
не изменилась. Уже проверенные записи `source=manual` сохраняются и при обновлении.

Для этой установки адрес `http://localhost:1235/v1` сохранён локально
в `narrations/lmstudio.json`:

```json
{"url": "http://localhost:1235/v1"}
```

Если LM Studio запущен в Windows, а сборка — в WSL, при недоступности
Windows localhost через Linux автоматически используется Windows `curl.exe`.
Параметры запросов передаются через stdin; менять сетевой режим сервера не требуется.
Для другого адреса сервера можно изменить этот файл или задать `LM_STUDIO_URL`.

Параметры передаются через переменные окружения: `LM_STUDIO_URL`,
`LM_STUDIO_MODEL`, а при включённой авторизации сервера — `LM_STUDIO_API_TOKEN`.
В качестве `LM_STUDIO_MODEL` используйте ключ модели из `/api/v1/models`.
Эти настройки должны совпадать при `make narrations` и `make clips`.

Для обновления автоматически подготовленных текстов:

```bash
make narrations NARRATION_FLAGS=--refresh
```

Правки вносятся в `segments` нужной картинки в `scripts.json`; для проверенного
текста установите `status=ready` и `source=manual`. Поле `enabled=false` отключает
озвучку. Можно задать `voice` с точным именем одного из двух голосов, чтобы закрепить
его за мемом. Статусы `no_text`, `review` и `error` не озвучиваются: изображение
останется в видео, а проблемы будут отмечены в отчёте. Уверенность модели не
гарантирует правильность текста; перед первым выпуском просмотрите отчёт.

## Озвучка и сборка

### Подборка фото-мемов голосами отправителей

Команда запускается из `video_builder/` в WSL. Для установки зависимостей
при первом запуске выполните `make install`.

```bash
make directed-memes
```

Команда берёт `export/result.json` и фотографии из Telegram-экспорта, сохраняет
их порядок и собирает `result/memes-by-author-llm.mp4`. Флаги позволяют
выбрать каталог другого экспорта и имя выходного файла.

```bash
make directed-memes DIRECTED_FLAGS='--export /path/to/export --output result/new.mp4'
```

Достаточно один раз настроить локальный файл `narrations/directed-memes.json`.
В примере используются абсолютные пути WSL и пути относительно `video_builder/`.

```json
{
  "author_voices": {"Имя из экспорта": "ID профиля VoiceStudio"},
  "lm_studio": {
    "url": "http://127.0.0.1:18473",
    "model": "qwen/qwen3.5-9b",
    "cli": "/mnt/c/Users/USER/.lmstudio/bin/lms.exe",
    "gpu": "0.25"
  },
  "voicestudio_cli": "/mnt/c/Users/USER/AppData/Local/Programs/VoiceStudio/resources/cli/voicestudio.exe",
  "whisper": {
    "cli": ".tools/whisper/whisper-cli.exe",
    "model": ".tools/whisper/ggml-small-q5_1.bin",
    "dtw": "small",
    "pitch_ffmpeg": "/mnt/c/ffmpeg/bin/ffmpeg.exe"
  }
}
```

Нужны локальные Vision-модель в LM Studio, движок OmniVoice и сохранённые
профили в VoiceStudio, [whisper.cpp](https://github.com/ggml-org/whisper.cpp)
с подробными JSON-таймкодами и FFmpeg с фильтром `rubberband`. Пути к CLI
позволяют запускать локальные сервисы из скрипта. Если сервисы уже работают,
поля `lm_studio.cli` и `voicestudio_cli` можно опустить. На Linux используйте
исполняемые файлы Linux. При необходимости укажите резервную модель Whisper
через `fallback_model` и `fallback_dtw` внутри секции `whisper`.

Для пересланных ботом фото имя берётся из подписи рядом с 👤, для прямых
публикаций — из `from`. Для нового отправителя добавьте пару имени и ID в
`author_voices`.

Для новых изображений LM Studio распознаёт реплики. Затем LLM выбирает формы
числительных, паузы между репликами и слова для интонационных акцентов.
Скрипт раскрывает цифры с сохранением значения, синтезирует голос автора
и применяет изменения высоты тона по таймкодам Whisper. Заданные в сценарии
длительность и пауза отдельной реплики сохраняются. Картинки со статусами
`no_text`, `review` или `disabled` показываются без речи.

Результаты отдельных мемов кэшируются в `temp_clips/directed-memes/`; там же
`manifest.json` содержит голоса, формы чисел, паузы и фактически применённые
акценты. После сбоя повторный запуск продолжает с сохранённых клипов.
Для параллельных сборок задавайте отдельные `--work-dir` и `--output`.

### Голоса друзей через VoiceStudio

Установите VoiceStudio для Windows и оставьте приложение открытым.
[Установка на Windows](https://github.com/debpalash/VoiceStudio/blob/main/docs/install/windows.md).

В Model Catalogue установите веса OmniVoice. Модель поддерживает русский язык.
В **Voice Cloning** сохраните по профилю для каждого друга, который согласен на
озвучку мемов своим голосом. Для OmniVoice возьмите 5–10 секунд чистой речи
одного человека без музыки и добавьте точную расшифровку записи.
[Инструкция по созданию профиля](https://dev.voicestudio.sh/docs/guides/voice-cloning).

В PowerShell выведите имена и ID сохранённых профилей:

```powershell
(Invoke-RestMethod http://127.0.0.1:3900/v1/audio/voices).voices |
    Where-Object type -eq profile | Select-Object name, voice_id
```

Из `video_builder/` в WSL запустите пробу с одним профилем, подставив его ID:

```bash
poetry run python voiceover_demo/build_preview.py --voicestudio --voice ID_1
```

Проба берёт до трёх мемов с готовыми репликами из текущего экспорта. Если реплик
ещё нет, запустите `make narrations`. Результат появится в
`voiceover_demo/output/voicestudio/ID_1/preview.mp4`.
Для полной сборки подставьте один или несколько ID:

```bash
make clips CLIPS_FLAGS='--voicestudio-voices ID_1 ID_2 --meme-seed 1'
make video
```

Для каждого мема случайно выбирается один профиль из списка. Чтобы закрепить
голос за всей сборкой, передайте `--meme-voice ID_1`. Чтобы закрепить его за
одним мемом, задайте `"voicestudio_voice": "ID_1"` в проверенной записи
`source=manual` в `narrations/scripts.json`. При сбое после повторов мем
остаётся без озвучки, а ошибка записывается в манифест.

В VoiceStudio темп по умолчанию снижен на 8%, между отдельными репликами
сохраняется пауза не короче 0,32 с. Темп можно задать через `--meme-rate`
при сборке или `--rate` в предпросмотре. Для OmniVoice сборщик запрашивает
32 шага генерации.
В отдельной реплике можно задать `voicestudio_duration` для целевой длительности
самой фразы. Поле `pause_after` задаёт тишину после неё. Оба значения в секундах.

Сборщик отправляет текст реплик и ID профиля в локальный API. Образцы голосов
хранятся в VoiceStudio. По умолчанию используются движок `omnivoice` и адрес
`http://127.0.0.1:3900/v1`. Переопределить их можно через `VOICESTUDIO_MODEL`
и `VOICESTUDIO_BASE_URL`. Если для API включена авторизация, задайте
`VOICESTUDIO_API_KEY`. Из WSL при недоступности локального адреса сборщик
пробует Windows `curl.exe`.

### Стандартная озвучка Edge TTS

```bash
make clips DIRECTED_MEMES=0
make video
```

`make clips DIRECTED_MEMES=0` подготавливает отсутствующие сценарии через LM Studio.
В Microsoft Edge TTS передаются только тексты реплик; картинки в сервис
озвучки не отправляются. В этой конфигурации распознавание локальное,
а синтез речи требует интернета. Записи кэшируются в `narrations/audio/`
по тексту, голосу и темпу. Сбой синтеза оставляет мем без голоса;
причина сохраняется в `temp_clips/manifest.json`.

При сетевой ошибке, пустом или непригодном аудио TTS делает до трёх попыток
выбранным голосом. Если они не помогли, весь мем заново озвучивается вторым
голосом (также до трёх попыток на реплику). Все реплики готового мема звучат
одним голосом. В манифесте сохраняются выбранный и фактический голоса,
признак `fallback_used`, история попыток и статистика кэша/запросов.

Распознавание LLM также повторяется до трёх раз при некорректном ответе.
После достижения лимита ответа он увеличивается с 2048 до 4096 токенов.
Лишний Markdown-символ после JSON и недостающая последняя `}` исправляются
с отдельной записью в журнале; неоднозначные ответы и лишний текст отклоняются.

Во время работы выводятся имя файла, этап, модель или голос, номер реплики,
попытка, время запроса, попадание в кэш и конкретная причина ошибки.
По завершении печатаются отдельные итоги LLM, TTS и кодирования, включая список
мемов с проблемами. Полный журнал JSONL каждого запуска сохраняется в
`narrations/logs/`; путь выводится при старте и записывается в манифест.
Он содержит тексты реплик и краткие фрагменты некорректных ответов модели,
без изображений в base64, HTTP-заголовков и API-токенов.

```bash
make clips CLIPS_FLAGS=--no-meme-voiceover
make clips CLIPS_FLAGS='--meme-seed 1'
make clips CLIPS_FLAGS='--meme-voice ru-RU-SvetlanaNeural --meme-rate=+10%'
```

`--meme-seed` воспроизводит выбор голосов для тех же файлов, независимо от
перемешивания клипов. `make clean` не удаляет тексты и кэш озвучки.
Они исключены из Git, как и исходный экспорт.

Без LM Studio можно подготовить черновики через Tesseract (`rus` + `eng`):

```bash
# Ubuntu / WSL: sudo apt install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng
MEME_RECOGNIZER=tesseract make narrations
MEME_RECOGNIZER=tesseract make clips
```

Все найденные Tesseract тексты имеют статус `review` и требуют проверки:
обычный OCR захватывает интерфейс и теряет части мемных надписей.
Путь к своему бинарному файлу можно задать через `TESSERACT_CMD`.

## Громкость

`make video` выравнивает громкость каждого клипа и заставки по EBU R128
к ориентиру **−16 LUFS**. Видео подходящего формата копируется без
перекодирования. Уже подготовленные `temp_clips/` можно использовать сразу:
повторять `make clips` не нужно.

Дополнительный проход читает только звук; постоянное усиление применяется
при подготовке сегментов к склейке. Для клипов с резкими пиками включается
ограничитель с ориентиром **−2 dBTP** и запасом для AAC. Основная динамика
сохраняется, максимальное усиление — **18 dB**. При срабатывании ограничителя
или достижении максимального усиления клип может остаться тише целевого уровня.
Тишина и звук ниже −50 LUFS не усиливаются.

Параметры находятся в `audio_normalization.py`. Отключить выравнивание:

```bash
make video VIDEO_FLAGS=--no-normalize-audio
```

Проверки (нужны `ffmpeg` и `ffprobe` в PATH):

```bash
poetry run python -m unittest discover -s tests -v
```
